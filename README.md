# Introduction to Git and GitHub - Final Project

This repository contains the final project work for the Introduction to Git and GitHub course. It demonstrates proficiency in using GitHub UI features, open-source collaboration, and Git command-line interface (CLI) operations.

## Project Details
* **Course:** Introduction to Git and GitHub
* **Author:** Abdul Waseem
* **Purpose:** Final assessment showcasing repository setup, licensing, code of conduct, contributing guidelines, and basic shell scripting.

## Included Files & Structure
- `README.md`: Project documentation and overview.
- `LICENSE`: Apache 2.0 license file governing the project terms.
- `CODE_OF_CONDUCT.md`: Standards and community guidelines for contributors.
- `CONTRIBUTING.md`: Guidelines on how to contribute, report bugs, and suggest ideas.
- `simple-interest.sh`: A Bash script calculator to compute simple interest based on user inputs.

## Technologies Used
* Git & GitHub (UI & CLI)
* Bash Scripting
