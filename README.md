## Simple Interest Calculator (`simple-interest.sh`)
This repository includes a Bash script (`simple-interest.sh`) that serves as a simple interest calculator.
- **Functionality:** It prompts the user to input the principal amount, the annual rate of interest, and the time period in years.
- **Calculation:** It computes the simple interest using the formula: $\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$
- **Usage:** Designed for demonstration and educational purposes within the scope of the Git and GitHub course.
